# Повторная проверка — 20 октября 2026

Проверяемый сценарий: экран запрашивает матчи по HTTP, проверяет ответ, отображает данные, позволяет менять фильтр, избранное и обновлять список.

| Проверка | Результат |
| --- | --- |
| Чистая установка `npm ci` | Успешно |
| `npm run typecheck` | Без ошибок |
| `npm run lint` | Без ошибок |
| `npm test` | 15 из 15 тестов прошли |
| Expo web-export | Сборка создана |
| `expo export --platform all` | Созданы web-bundle и Hermes-bundles для Android/iOS |
| `npm run web` | HTML и JS bundle: HTTP 200 |
| Браузер → реальный источник → список | HTTP 200, 8 матчей, без перехвата ответа |
| Часовой пояс Europe/Moscow | Первый матч отображается в 16:00 |
| Фильтры | Все: 8, предстоящие: 4, завершенные: 3 |
| Избранное | Изначально выключено, переключается независимо и сохраняется при смене фильтра |
| Таймер | Идет, сбрасывается после успеха; после ошибки не сбрасывается |
| Ошибки HTTP и повтор | Предыдущие данные сохраняются, повтор восстанавливает загрузку |
| Неверный JSON и структура | Сообщение об ошибке, без падения экрана |
| Пустой ответ и пустой фильтр | Разные понятные сообщения |
| Тайм-аут 15 секунд | Снимается состояние обновления, работает повтор |
| 375 × 812, 812 × 375, 1440 × 1000 | Горизонтального переполнения нет |
| Ошибки JavaScript страницы | Не обнаружены |

Найден и исправлен недочет: системные сетевые ошибки раньше могли отображаться на английском. Добавлены русские сообщения для ошибок fetch и синтаксиса JSON, а также три регрессионных теста.

Ошибки, пустые ответы и тайм-ауты воспроизводились управляемыми HTTP-ответами на основе исходного JSON. Загрузка настоящего публичного JSON проверена отдельно без подмены ответа. Для этого тестовому Chromium потребовалось доверять сертификату прокси среды; настройки безопасности приложения не изменялись.

Повторно сверены обязательные пункты исходного задания и опубликованный код. TypeScript, ESLint и все 15 тестов проходят. Экспорт для всех платформ успешно собрал web и Hermes-bundles Android/iOS; это проверка сборки JavaScript, а не запуск приложения на устройстве.

Проверки на физическом iOS/Android-устройстве не выполнялись. Результаты браузерных сценариев и экспорта не заменяют проверку Expo Go на телефоне.
